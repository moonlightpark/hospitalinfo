01개요

굿닥 앱은 React Native(New Architecture, Hermes 엔진)로 만든 하이브리드 앱입니다. 화면과 비즈니스 로직은 11 MB 크기의 Hermes 바이트코드 번들(assets/index.android.bundle, HBC v96, 함수 48,863개)에 있습니다. Kotlin/Java 쪽은 앱 진입점과 기기 기능 4가지(GPS, 루팅 탐지, 로컬 푸시, 삼성 헬스)만 직접 구현했습니다.

서버 통신은 GraphQL(Apollo Client)이 중심입니다. 모바일 접수와 진료실 상태처럼 실시간성이 필요한 부분은 WebSocket과 GraphQL Subscription을 씁니다. 비대면 진료 화상통화는 Vonage OpenTok, 통화 수신 UI는 CallKeep(Android ConnectionService)로 구현합니다. JS 번들은 CodePush로 스토어 배포 없이 갱신할 수 있습니다.

관찰 APK에서 직접 확인한 사실추론 이름·배치에서 유추한 해석
