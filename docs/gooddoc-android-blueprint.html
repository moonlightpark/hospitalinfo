01개요

굿닥은 React Native(New Architecture, Hermes 엔진) 하이브리드 앱입니다. 모든 화면과 비즈니스 로직은 11 MB 크기의 Hermes 바이트코드 번들(assets/index.android.bundle, HBC v96, 함수 48,863개)에 있고, Kotlin/Java 레이어는 앱 진입점과 기기 기능(GPS, 무결성/루팅 탐지, 로컬 푸시, 삼성 헬스)만 구현합니다.

서버 통신의 중심은 Apollo GraphQL 단일 클라이언트입니다. HTTP는 일반 API와 진료(clinic) API 두 엔드포인트로 분기하고(split link), 실시간은 graphql-ws 구독과 접수 전용 WebSocket 두 경로를 씁니다. 화상진료는 Vonage OpenTok, 통화 수신 UI는 CallKeep, 결제는 PortOne v2 + 토스페이먼츠, JS 번들은 CodePush로 OTA 갱신합니다.

관찰 APK·디컴파일에서 직접 확인추론 이름·구조에서 유추

10결제·실시간·OTA 설계

결제 (PortOne v2) 관찰

  • WebView에 PortOne v2 browser-sdk(cdn.portone.io/v2/browser-sdk.js)를 띄워 결제 UI 렌더
  • PORTONE_STORE_ID + 채널키로 빌링키 발급
  • CreatePaymentMethodV2(billingKey) → 서버에 결제수단 등록
  • CreateTreatmentPaymentV2(treatmentId, paymentMethodId, treatmentFee, installmentMonths)로 진료비 결제
  • 카드정보는 maskedCardNumber·issuer만 보관, 실번호는 미저장
  • 토스페이먼츠 무이자 할부 안내 연계

실시간 통신 관찰

  • graphql-ws 구독: 진료·예약·처방주문 상태 변경 push
  • 접수 WebSocketManager: 병원별 대기열. 재연결 로직(WS_MAX_TRY_COUNT), 암호화된 Authorization 헤더
  • 화상: OpenTok 세션/토큰을 opentokConnection으로 수신, CallKeep으로 수신 화면 표시
  • VoIP 푸시(OneSignal 별도 app id)로 통화 수신

OTA 갱신 (CodePush) 관찰

  • MainApplication.getJSBundleFile()를 CodePush 번들 경로로 재정의 → 스토어 배포 없이 JS 갱신
  • 설치 모드: Immediate / OnNextRestart / OnNextResume / OnNextSuspend
  • 실패 시 롤백(getLatestRollbackInfo, DEFAULT_ROLLBACK_RETRY_OPTIONS), 이벤트 codepush_update_success/rollback 기록
